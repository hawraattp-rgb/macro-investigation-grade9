# مراسلون رقميون | درس تفاعلي للصف التاسع

موقع تعليمي عربي تفاعلي في مادة تقنية المعلومات، بأسلوب التحقيق الصحفي، يدرّب الطالب على التحقق من المصادر وتنظيم المعلومات وكتابة تقرير مسؤول، مع إبراز قيم الهوية العُمانية.

## تشغيل الموقع
افتح `index.html` في المتصفح، أو فعّل GitHub Pages لنشره على الإنترنت.

## النشر عبر GitHub Pages
1. افتح **Settings → Pages** في هذا المستودع.
2. إذا كان الخيار متاحًا، اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`، ثم اضغط **Save**.
3. انتظر حتى يكتمل النشر. سيكون الرابط غالبًا:
   https://hawraattp-rgb.github.io/macro-investigation-grade9/

يوجد أيضًا سير عمل GitHub Actions في `.github/workflows/pages.yml` لمحاولة النشر تلقائيًا. قد تتطلب أول مرة تفعيل GitHub Pages من إعدادات المستودع.

## ملاحظات تعليمية
- الأرقام في تحدي الاستبانة والسيناريو الإخباري افتراضية وموسومة بأنها للتدريب.
- لا يحتاج الموقع إلى تثبيت حزم أو خادم.
